## Decisions Made

- **Rung 1 and it stays rung 1.** Amazon serves the control in the impersonated-
  HTTP response. Reaching for rung 3 to make Amazon resemble Target would spend a
  Chrome process to obtain bytes curl already returned, and the ladder says stop
  at the first rung that works. Amazon is therefore the cheapest transport in
  this project with the most fragile extraction in it — the exact combination
  03.1-05 widened `degraded` for, three days before anything needed it.
- **The seller default is per page family, and this is the most dangerous line in
  the plan had it gone the other way.** On Target, absence of a seller block is
  the first-party signal (measured). Carrying that default to Amazon would have
  meant every unreadable Amazon buy box reporting as sold by Amazon, so a
  reseller whose block failed to parse would alert. On Amazon the default is
  `None` → UNKNOWN on a marketplace.
- **One reader widened, not a second written.** Amazon's control is a void
  `<input>` labelled by its `value` attribute; Target's is a `<button>` with a
  per-product id prefix. Both now run through `_AddToCartParser`, and M8 still
  covers the single availability decision for both.
- **No unavailable marker for Amazon.** All three pages fetched were available,
  so nothing here has ever seen what Amazon renders for an unbuyable item.
  Implementing a marker for an unobserved page shape would be guessing.
- **Rule 6 needs a measurement, not just an anchor.** The obvious line form was
  in the plan's own text and is satisfiable by typing the sentence.
- **Rule 6 reads REFUSED sections only**, and the shipped counterexample proves
  why the body predicate cannot substitute for that: § Target's
  `Refusal observed (rung 1): not a block — HTTP 200, 314,757 B` has a status
  code and two byte counts and records a **non**-refusal.
- **Amazon gets a real product watch, not only a control.** It is the one
  retailer of the hard two that lists the GO Plus +.

## Issues Encountered

**The `robots.txt` and Conditions-of-Use tension is decided, not resolved.** The

**Nothing was deleted from the historical record.** § Amazon still carries the
