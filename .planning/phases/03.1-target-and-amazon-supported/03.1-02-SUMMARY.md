## The exact names 03.1-03 needs

**The DOM reader** — `boty/parse.py`:

```python
def add_to_cart_offers(html: str) -> list[Offer] | None:
```

One positional argument, no keywords. Returns a **single-element** list, or
`None`. `None` means "the control this reader looks for is not on this page, or
its text is not one this reader recognises" — never `[]`, never
`available=False`. Module constants beside it: `ADD_TO_CART_PHRASES`
(`("add to cart", "preorder", "pre-order")`) and `TARGET_FIRST_PARTY_SELLER`
(`"target"`), both public; `_CONTROL_ID_PREFIX`, `_PARTNER_TEST`, `_PRICE_TEST`,
`_PARTNER_PREFIX_RE` and `_TargetPdpParser` are private.

**The `allow_dom` keyword** — `boty/retailers.py`:

```python
def _verdict_from_html(
    watch, html, *, url, first_party_only, rung, sku=None, allow_dom=False,
) -> Result:
```

Keyword-only, defaulting `False`, declared **after** `sku`. Behaviour, and the
third bullet is the one that matters:

1. `allow_dom=False` — byte-identical to before. Every shipped adapter is
   unchanged; nothing falls through to the DOM reader.
2. `allow_dom=True` **and a structured reader succeeded** — extraction stays
   `Extraction.STRUCTURED`. The label follows the reader that produced the offers.
3. `allow_dom=True` **and both structured readers returned None** — the DOM reader
   runs, `source` becomes `"add-to-cart control"`, and the extraction is
   `Extraction.DOM` **whether or not the DOM reader found anything**. This is
   plan-check W-2 and the path a broken render takes in production; it is pinned
   by `test_a_target_dom_reading_that_found_nothing_is_still_a_dom_reading`.

**Every `Result(...)` return inside `_verdict_from_html` now carries
`extraction=extraction`** — all six of them, verified by an AST sweep rather than
by eye. The `extraction=` keyword sits **after** `rung=rung,` on each, so M2's
twelve-space anchor and M3's `if first_party_only:` are byte-identical.

**The adapter** — `boty/retailers.py`:

```python
def check_target_browser(watch: Watch, *, first_party_only: bool = True) -> Result:
```

The same signature as `check_bestbuy_browser`. It renders `watch.target`
directly — Target is addressed by URL, so **no `sku=` is passed**; there is no
search redirect to bind against. Both error paths (`Blocked`, `FetchError`)
return `Result(..., rung=Rung.BROWSER, extraction=Extraction.DOM)` with their
detail through `_redact_host_paths`, and the success path delegates to
`_verdict_from_html(..., rung=Rung.BROWSER, allow_dom=True)`.
