`state_path`, which `tests/test_cli_watch.py:1056-1060` **itself calls a model**. There is no instant
at which that sentence was accurate, so there is nothing to date and nothing to supersede. A false
claim left standing with a note beside it is still a published false claim, in a phase whose entire
thesis is that a claim must not exceed what was observed. **So: corrected in place, in every file that
carries it, with the correction itself recorded in the addendum so the change is visible rather than
silent.**

**The behaviour is verified and the claim about the behaviour is NOT weakened.** `State.save` writes

## GAP 3 — A GATE THAT CANNOT FIRE IS THIS PHASE'S OWN SUBJECT WEARING THE FIX'S CLOTHES

`tests/test_dashboard.py::test_the_dashboard_script_parses` exists because the CR-01 fix broke the
page: a paragraph of this project's usual back-quoted prose went **inside** the row's template
literal, a backtick in it closed the literal, the page stopped parsing and rendered nothing at all —
and every structural assertion in that file stayed green, because a regex looking for
`esc(w.availability)` finds it just as happily in a file the browser refuses to run. The gate was
added the same day, at `9e7d302`, to close exactly that.

**It has never run in the environment the project's own gate runs in.** Measured while this plan was
written, and to be re-measured at execution:

- `command -v node` in a non-login shell on this box: **not found.**
- The same, inside a `make` recipe: **not found** — `make` inherits the invoking shell's `PATH` and
  does not source `nvm`.
- The only node on this host: `/home/dan/.nvm/versions/node/v24.16.0/bin/node`.
- `.venv/bin/python -m pytest tests/ -q -rs` → `883 passed, 1 skipped`, and the one skip is
  `tests/test_dashboard.py:491: no JavaScript runtime on PATH; the parse check is opportunistic`.
  **It is the only skip in the entire suite.**

So the deliverable is measurable to a single number: **that skip becomes a pass, and the suite's skip
count goes to zero.** Record both tails verbatim.

**Two failure modes are forbidden, and they pull in opposite directions.**

*Making it a hard requirement* breaks `REQUIREMENTS.md` § Non-Functional's fresh-clone rule — *"a
retailer's PRIMARY path must work for someone who clones the repo and adds no credentials"* — and the
module's own docstring, which rejects requiring a JavaScript runtime in as many words: *"a check that
does not run is worse than one that is coarse."* A contributor with no node must not get a red tick.

*Leaving it able to skip silently* is the defect. A skip prints as `1 skipped` under `-q` and nothing
else; the reason lives in the test file where nobody reading a gate transcript will meet it.

**The fix is therefore two small moves, and neither is a dependency.** The search widens past `PATH`
into the version-manager install roots, using nothing but `shutil`, `glob` and `os.path` — all
standard library, so `REQUIREMENTS.md` § Non-Functional's small-dependency-surface rule is untouched
and no legitimacy gate is triggered. And the gate transcript starts printing skip reasons, so the day
a skip returns it announces itself with the list of places the test looked, rather than as a bare
count that reads like coverage.
