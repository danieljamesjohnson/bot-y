<objective>
This is the plan that decides whether "`pip install bot-y` works" is a claim or a
measurement.

Every other artefact in this phase can be read. A wheel cannot: it either
installs and runs somewhere that is not this repository, or it does not, and the
only way to know is to put one somewhere that is not this repository and run it.
`[tool.setuptools.packages.find] include = ["boty*"]` means `scripts/`, `tests/`
and `config/` are not packaged, so anything the installed CLI reaches for outside
`boty/` is a packaging bug that exactly one check in this project can find. An
editable install proves nothing about a wheel; it *is* the checkout.

**That check was run during planning, and it found one.** On a wheel installed
into a clean venv, `boty --help` exits 0 — and `boty check`, the first command
README teaches, dies with an uncaught `FileNotFoundError` naming
`config/products.yaml`, a path inside a directory this package deliberately does
not ship. That is not cosmetic. It is the same shape as the missing `LICENSE`
04-02 found and the missing linter 04-03 found: a contract asserted at the
producing end and unimplemented at the consuming one, sitting inside the very
criterion this phase is trying to close. It gets fixed here, because the plan
whose job is to prove the artifact does not get to file a bug against it instead.

The rest is release engineering, all of it local: the bump to `1.0.0` that 04-02
deliberately left alone, `CHANGELOG.md`, a tag-triggered publish workflow that
authenticates to PyPI by OIDC rather than by a stored token, and README's
`## Install` gaining the PyPI line together with the warning that `pip install
boty` — one hyphen away — fetches an unrelated package last released on
2012-03-10.

Purpose: REQ-11, and the offline half of Phase 4 criteria 3 and 5.

Output: `CHANGELOG.md`, `scripts/release_check.py`, `.github/workflows/release.yml`,
`make release-check`, an honest fresh install, and a `pyproject.toml` that says
1.0.0.

**This plan closes neither criterion 3 nor criterion 5, and must not try.** Both
