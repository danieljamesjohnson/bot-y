<objective>
Write the contributor documentation REQ-09 asks for, and put a gate under it so it
cannot rot into a doc that cites things which are not there.

Three documents and one test. `docs/adding-a-retailer.md` walks **Nintendo** end to
end — the retailer that needs no adapter code at all — because the lesson worth
teaching first is that the default answer is "no adapter", and then walks **Amazon**
as the case where `check_html` reads the page perfectly and says UNKNOWN forever, so a
DOM reader is genuinely needed. `CONTRIBUTING.md` covers setup, the commit hook, the
checks and what a PR has to carry. `README.md` gains two short prose sections that
point at both.

The test is what makes this different from a doc that reads well. It reads the
contributor docs the way `tests/test_support_matrix.py` reads the README: cited paths
must exist, citations may not carry line numbers (a line number is a citation that
rots — and 04-03 is about to move hundreds of them), pinned symbols must occur in both
the doc and the file it names, required headings must be present, and each rule is
watched failing against a deliberately corrupted copy of the real file.

Purpose: REQ-09, and criterion 1 of Phase 4. Also preserves criterion 4 — this plan
edits README free prose only and re-runs the matrix test as its own verification.
Output: `tests/test_contributor_docs.py`, `docs/adding-a-retailer.md`,
`CONTRIBUTING.md`, and two new prose sections in `README.md`.
